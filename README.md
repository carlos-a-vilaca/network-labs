# 🌐 Network Labs

Laboratórios de redes que vou desenvolvendo durante os meus estudos, feitos em **Cisco Packet Tracer**.

Neste repositório documento o que aprendo: cada laboratório inclui a topologia, a configuração 
que fiz e as conclusões que tirei.


## 📚 O que vais encontrar aqui

- Montagem de pequenas topologias de rede
- Configuração básica de dispositivos
- Endereçamento IPv4 e cálculo de sub-redes
- Testes de conectividade e resolução de problemas

## 🧪 Laboratórios

| Lab | Descrição | Conceitos |
|---|---|---|
| [01 - Duas sub-redes](./01-duas-subredes) | Duas redes ligadas por [router/switch] | IPv4, endereçamento, conectividade |
| [Prática de sub-redes](./subnetting-practice) | Exercícios de cálculo de máscaras | Sub-redes, máscaras, hosts por rede |

## 🗂️ Como está organizado

Cada laboratório tem a sua pasta com:
- `README.md` com o objetivo, a tabela de endereçamento e o que aprendi
- Ficheiro `.pkt` para abrir no Packet Tracer
- Capturas de ecrã da topologia e dos testes

## 🛠️ Ferramentas
